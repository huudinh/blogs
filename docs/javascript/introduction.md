JavaScript là **ngôn ngữ lập trình chạy trong trình duyệt web** (và có thể chạy trên server) giúp website **tương tác và sống động hơn**.

---

## Vai trò của JavaScript

| Công nghệ      | Vai trò                                              |
| -------------- | ---------------------------------------------------- |
| **HTML**       | Tạo nội dung → chữ, hình ảnh, bố cục                 |
| **CSS**        | Làm đẹp giao diện → màu sắc, hiệu ứng, responsive    |
| **JavaScript** | Thêm logic, tương tác → xử lý hành vi của người dùng |

➡ Nhờ JavaScript, website không còn “tĩnh” nữa mà trở nên **động** và thông minh.

---

## JavaScript dùng để làm gì?

* Form kiểm tra dữ liệu (bắt buộc nhập email, số điện thoại…)
* Hiệu ứng menu, slider, popup
* Load dữ liệu mà **không cần tải lại trang** (AJAX)
* Xử lý logic trò chơi, ứng dụng web
* Điều khiển DOM (thay đổi nội dung trang khi người dùng thao tác)
* Viết ứng dụng mobile, desktop, server (Node.js)

---

## Ví dụ nhỏ

Click vào button → đổi nội dung text:

```html
<button onclick="document.getElementById('demo').innerText='Xin chào!'">
  Click thử
</button>
<p id="demo">Nội dung sẽ thay đổi</p>
```

---

## JavaScript chạy ở đâu?

* **Trình duyệt**: Chrome, Firefox, Edge…
* **Máy chủ** với Node.js (ứng dụng web, API…)
* **Mobile, Desktop, IoT** → JS rất linh hoạt

---

## Kết luận

> JavaScript là ngôn ngữ quan trọng nhất để lập trình web hiện đại.
> Nếu muốn phát triển website chuyên nghiệp → gần như bắt buộc phải biết JavaScript.
